# Golden set

50-100 anonymised real cases with known outcomes, collected with consent during the
concierge pilot (IMPLEMENTATION_PLAN.md section 16). Every change to a Grok model
slug or prompt should re-run the full set before deploying -- model drift is a real
risk with a vendor that revises models every few months.

Not populated yet: this is empty until the Phase 1 concierge pilot produces real,
consented cases.
